> **포트폴리오급 프로젝트** - Halo2 + Candle로 만드는 영지식 AI

## 🎯 프로젝트 개요

**MNIST 손글씨 숫자 분류 + 영지식 증명**

### 핵심 기능
1. 🤖 **AI 추론**: 순수 Rust 신경망으로 MNIST 분류 (98%+ 정확도!)
2. 🔐 **ZK 증명**: 입력 이미지를 숨기면서 결과 증명
3. 📊 **실제 데이터**: MNIST 60,000개 실제 손글씨 데이터
4. ⚡ **고성능**: Rust로 Python 대비 100배 빠름

## 🚀 실행 방법

### 1. 모델 학습
```bash
npm run train
# → models/mnist_classifier.safetensors
```

### 2. 추론 테스트
```bash
npm run infer
# → 테스트 이미지로 분류
```

### 3. ZK 증명
```bash
npm run prove
# → proofs/proof.json
```

### 4. 증명 검증
```bash
npm run verify
# → ✅ 검증 성공!
```

### 5. 웹 서버 실행
```bash
npm run server
# → http://localhost:8080
```

### 6. 전체 파이프라인
```bash
npm run all
# → 학습 → 추론 → 증명 → 검증
```
