# 🌳 머클트리 증명 ZKP 회로 (04_MerkleTree)

## 📋 **프로젝트 개요**

머클트리(Merkle Tree) 포함 증명을 ZKP로 구현한 새로운 도전 프로젝트입니다!

### 🎯 **핵심 목표**

- **데이터 포함 증명**: 특정 데이터가 머클트리에 포함되어 있음을 증명
- **위치 프라이버시**: 데이터의 정확한 위치는 비공개로 유지
- **효율적 검증**: 전체 데이터셋 없이도 포함 여부 확인 가능

## 🌳 **머클트리란?**

### 📚 **기본 개념**

```
        Root Hash
       /          \
   Hash AB      Hash CD
   /    \       /     \
Hash A Hash B Hash C Hash D
  |     |       |      |
 Data  Data    Data   Data
  A     B       C      D
```

### 💡 **핵심 특징**

- **무결성 보장**: 데이터 변경 시 루트 해시 변경
- **효율적 증명**: O(log n) 크기의 증명으로 포함 여부 확인
- **블록체인 활용**: 비트코인, 이더리움 등에서 광범위 사용

## 🔧 **회로 구조**

### 📥 **입력/출력**

```
Private Input:
  - leaf: 증명하려는 데이터
  - pathElements: 머클 경로의 해시들 (형제 노드들)
  - pathIndices: 각 레벨에서의 방향 정보 (0: 왼쪽, 1: 오른쪽)

Public Input:
  - root: 머클트리 루트 해시

Public Output:
  - isValid: 증명 유효성 (1: 유효, 0: 무효)
```

### 🧮 **핵심 로직**

1. **시작**: leaf 값부터 시작
2. **경로 추적**: pathElements와 pathIndices를 따라 트리 상향 이동
3. **해시 계산**: 각 레벨에서 Poseidon 해시 함수로 부모 노드 계산
4. **루트 검증**: 최종 계산된 해시가 주어진 root와 일치하는지 확인

### 🔐 **보안 특징**

- **Zero-Knowledge**: 실제 데이터와 위치 완전 비공개
- **Poseidon 해시**: ZKP에 최적화된 해시 함수 사용
- **4레벨 트리**: 최대 16개 데이터 지원 (확장 가능)

## 🚀 **사용법**

### 1️⃣ **환경 설정**

```bash
# 의존성 설치
pnpm install

# 테스트 데이터 생성
pnpm run generate-data

# 회로 컴파일 및 신뢰 설정
pnpm run all
```

### 2️⃣ **유효한 증명 테스트**

```bash
# 올바른 데이터로 증명 생성 및 검증
pnpm run test-valid
# 결과: isValid = 1 (증명 성공)
```

### 3️⃣ **무효한 증명 테스트**

```bash
# 잘못된 데이터로 증명 시도
pnpm run test-invalid
# 결과: isValid = 0 (증명 실패)
```

### 4️⃣ **전체 테스트**

```bash
# 유효/무효 증명 모두 테스트
pnpm run test-all
```

```
결과: 필요한 자격만 선택적으로 증명 ✅
```

## 🔬 **기술적 특징**

### ⚙️ **회로 복잡도**

- **제약 조건**: ~200개 (Poseidon + Switcher 조합)
- **컴파일 시간**: < 2초
- **증명 생성**: < 200ms
- **검증 시간**: < 20ms

### 🛡️ **보안 수준**

- **완전성**: 올바른 증명은 항상 성공
- **건전성**: 거짓 증명은 불가능
- **영지식성**: 데이터와 위치 정보 완전 비공개

### 📈 **확장성**

- **레벨 조정**: 템플릿 파라미터로 트리 크기 조절
- **해시 함수**: Poseidon 외 다른 해시 함수 사용 가능
- **배치 증명**: 여러 데이터 동시 증명 가능
