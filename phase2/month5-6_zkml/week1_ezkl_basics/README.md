## 🔐 암호화 이해하기

### 무엇이 암호화되는가?

#### ✅ **암호화되는 값 (Witness → Proof)**

```
1. 모델 파라미터
   - weight = 2.0  ← 숨겨짐!
   - bias = 1.0    ← 숨겨짐!

2. 계산 과정
   - Step 1: 2.0 × 3.0 = 6.0  ← 숨겨짐!
   - Step 2: 6.0 + 1.0 = 7.0  ← 숨겨짐!

3. 중간값
   - temp = 6.0    ← 숨겨짐!
```

#### 🔓 **공개되는 값 (설정에 따라)**

```
• 입력: 3.0 (Public 설정시)
• 출력: 7.0 (Public 설정시)
• 증명: test.pf (17KB)
```

### 어떻게 암호화되는가?

```
[1단계] PyTorch 모델 (평문)
   model.weight = 2.0
   model.bias = 1.0
          ↓
[2단계] ONNX 변환 (바이너리)
   simple_linear.onnx (2KB)
   - weight, bias 포함
   - 바이너리 형태 (읽기 어려움)
          ↓
[3단계] Witness 생성 (평문 - 비공개)
   witness.json
   - 입력: 3.0
   - 중간값: 6.0
   - 출력: 7.0
   - 모든 계산 과정 기록
          ↓
[4단계] ZK 증명 생성 (암호화!)
   test.pf (17KB)
   - Witness를 KZG 커밋먼트로 암호화
   - 타원곡선 연산 사용
   - Proving Key (528MB) + SRS (16MB) 활용
          ↓
[5단계] 검증
   ✅ "3 넣으면 7 나온다" 증명됨
   ❌ "어떻게?"는 알 수 없음
```

### 암호화 알고리즘

- **KZG (Kate-Zaverucha-Goldberg) 커밋먼트**
  - 다항식 커밋먼트 스킴
  - BN254 타원곡선 사용
  - Trusted Setup (SRS) 기반

### 보안 수준

```
파일 크기:
• Witness: 평문 (증명자만 보유)
• Proof: 17KB (완전 암호화)
• PK: 528MB (증명 생성용)
• VK: 257KB (검증용)

보안:
• 중간값 역산: 불가능
• 모델 파라미터 추출: 불가능
• 계산 과정 추적: 불가능
```

## 💡 핵심 인사이트

> **ZKML = ML 모델의 ZK 증명**
>
> 1. **프라이버시**: 입력 데이터 보호
> 2. **검증가능성**: 계산 결과 무결성 증명
> 3. **투명성**: 모델 로직 공개 없이 신뢰 구축
> 4. **암호화**: 추론 과정(Witness)을 ZK Proof로 암호화

### 🎯 핵심 개념

```
암호화 대상 = Witness (모든 계산 정보)
암호화 결과 = Proof (17KB)
보호 대상 = 모델 IP + 프라이버시
```

### 💼 실무 활용 예시

#### 예시 1: AI API 서비스 검증

```
회사: "GPT-4 사용!" + ZK Proof 제공
사용자: Proof 검증 (1초) → ✅ 확인됨
→ 사기 방지, 신뢰 보장
```

#### 예시 2: 의료 AI (프라이버시)

```
환자 데이터 (Private) → AI 추론 (로컬)
→ ZK Proof 생성 → 병원에 전달
병원: 데이터 못 봄, 진단 결과만 확인
→ GDPR 준수, 개인정보 보호
```

#### 예시 3: 블록체인 AI

```
AI 모델 (25MB) → 로컬 실행
→ Proof (17KB) → 스마트 컨트랙트
→ 가스비 절감 + 검증 가능
```
